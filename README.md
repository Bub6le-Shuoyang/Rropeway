# Rropeway Desktop

当前版本：`v0.11.0`

已保存项目支持自动保存；项目级撤回支持 `Ctrl+Z`，最近项目列表会持久记录并自动清理失效路径。
支持浅色、夜间和跟随系统三种主题，主题与界面大小设置会保存在本机。
设置菜单中的“皮肤编辑”提供暖纸书房、深海夜航两套内置皮肤，并支持自定义背景图、界面配色、透明度、模糊、圆角、密度和字体。皮肤背景保存在 Electron 本机用户数据目录，不会写入剧本仓库。

Rropeway 是一个离线的游戏对话脚本编辑器，基于 Electron，面向 Windows 桌面使用。

## 开发启动

```powershell
npm install
npm start
```

## 快捷键

- `Ctrl + N`：新建项目
- `Ctrl + O`：打开 `.scriptroom` 项目
- `Ctrl + S`：保存项目

## 构建 Windows 安装包

```powershell
npm run dist
```

安装包会输出到 `dist/`，支持自定义安装目录并创建桌面快捷方式。

## 项目文件

`.scriptroom` 是项目入口索引，只保存当前数据版本和各分卷文件的位置，不再承载整套剧本内容。项目数据按职责拆分为 JSON，场景各自使用独立文件：

```text
项目名称/
├─ 项目名称.scriptroom
├─ 项目名称.scriptroom.backup
├─ project-data/
│  └─ revisions/
│     ├─ <当前版本>/
│     │  ├─ project.json
│     │  ├─ characters.json
│     │  ├─ assets.json
│     │  ├─ relationship-graph.json
│     │  ├─ scene-flow.json
│     │  ├─ chapters.json
│     │  ├─ chapters/<章节>.json
│     │  └─ scenes/<场景>.json
│     └─ <上一版本>/
└─ assets/
```

`project.json` 保存名称与简介，角色、素材、关系图、流程图分别保存；章节文件只索引所属场景，每个场景文件保存该场景的对白、旁白、分段和选择。导入的图片/音频仍会复制到项目旁的 `assets/` 目录中，数据文件只保存相对路径，移动整个项目目录后仍可使用。

每个角色的表情素材使用独立目录：正方形头像组存放于 `assets/characters/<角色ID>/avatars/`，完整立绘组存放于 `assets/characters/<角色ID>/portraits/`。同一组可以保存普通、开心、生气等多个表情，并分别指定默认头像和默认立绘；头像支持独立别名，也可以直接从立绘裁剪生成。

保存时会先完整写入一个新版本目录，确认全部分卷成功后才原子切换 `.scriptroom` 索引；项目保留当前与上一版本，`.backup` 指向上一版索引。任意分卷损坏时会尝试从上一版本恢复，并在界面提示重新保存。旧版单 JSON 项目仍可直接打开，首次保存时自动迁移为分卷结构，原单文件会保留为首次备份。

## 当前能力

- 章节、场景、对白、旁白、玩家选择分支
- 玩家选项可搜索并关联全项目“关键节点”对白，支持按章节筛选
- 写作检查会识别空对白、未设置角色、对白过长、失效素材、缺少立绘、重复关键节点和未关联选项，并可跳转修复
- 全项目流程图支持自由拖动场景、跨章节设置“下一场”、显示选择分支，并按流程起点进行完整预览
- 当前章节支持逐条点击预览，主视角角色显示在右侧、其他角色显示在左侧，场景结束后可继续进入本章下一场景
- 角色关系图支持无限坐标拖动、画布平移、30%–250% 缩放、双向关系与可编辑便签，位置和内容随项目自动保存
- 场景新增、重命名和切换
- 选择角色后添加对白，避免产生无角色内容
- 可增删的多个自定义状态标签
- 对白分段与分段主视角角色
- 分段纵轴导航与一键回到顶部
- 对白文字颜色、粗体、斜体、字号和对齐格式
- 左侧手柄拖拽排序与单条内容删除
- 撤销/重做和未保存状态
- 关闭窗口前保存/不保存/取消
- 临时草稿自动保存与恢复
- 图片素材绑定为场景背景或对白立绘
- 本地项目保存和素材导入
